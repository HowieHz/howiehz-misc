# MIDI 音游

在浏览器本地读取 `.mid` 谱面，用 88 键 MIDI 键盘或 QWERTY 键盘弹奏并判定。支持倍速、宽松判定、演奏导出与回看；文件不会离开当前设备。

## 使用说明

- **导入 MIDI**：拖放或选择 `.mid` 文件作为谱面；想回看之前导出的演奏时，勾选「回放模式」。
- **模式**：判定模式（载谱弹奏并判定、录音）、自由录音（无谱自由弹并录音）。
- **回放模式**：只回看演奏，自动点亮琴键并把每个音判为完美。
- **输入**：优先 Web MIDI（88 键）；浏览器不支持时用 QWERTY 键盘——白键 `A S D F G H J K L ; '`、黑键 `W E T Y U O P`，`Z`/`X`（或方向键）平移八度，空格开始、暂停或继续。
- **键位提示**：设置里可选「自动 / 显示 / 隐藏」，在琴键上显示对应键盘字符。
- **倍速**：滑条调整 0.25×–3×，同时显示有效 BPM；判定窗口不随倍速缩放（固定毫秒）。
- **预备拍**：开始或继续时先响 4 拍节拍器预备拍，随后正式进入。
- **节拍器**：判定模式与自由录音都可开启；判定模式跟随谱面 BPM（含倍速），自由录音用自选 BPM。
- **显示**：设置里可调画面上方显示未来多少秒的音符（默认 3 秒），并可开关小节线。
- **判定**：默认完美 ≤80ms、良好 ≤160ms、差 ≤300ms（阈值可调），超过即为漏；弹错音也计为漏。perfect 按「人耳听不出明显弹偏」的宽度设定。
- **音源**：胶囊切换「按下时播放音源 / 自动播放音源」；旁边的「静音音源」开启后应用全静音并禁用胶囊（适合自带音源的电钢琴）。回放模式强制自动播放，自由录音强制按下时播放。
- **音色**：可选内置合成音色（默认电钢琴），或加载本地 SoundFont（`.sf2`）音色库并挑选预设。
- **配置生效**：判定阈值、倍速、音源等在播放/暂停中修改，会提示「重新开始后生效」。
- **导出演奏 MIDI**：两种模式都录制你的弹奏，可导出 `.mid`；判定模式导出沿用谱面节奏，自由录音导出写入自选节拍器 BPM。
- **全屏**：点「全屏游玩」或按 `F11`，仅保留游玩画面。

页面默认只显示谱面用到的音域（上下各留一音），可在「设置」中显示全部 88 键。
