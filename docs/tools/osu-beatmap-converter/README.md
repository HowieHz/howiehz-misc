# osu! 铺面转换器（std → mania）

[English](../../en/tools/osu-beatmap-converter/) | **简体中文**

将多个本地 `.osu` 文件转换为 osu!mania 谱面。文件在浏览器中读取、转换和下载，不会离开当前设备。

## 工作流

1. 拖放或多选 `.osu` 文件；每个文件会成为一个独立队列行，可继续追加或移除。
2. 调整目标键数、SV 和完整的 1K 转多键参数。
3. 选择“开始转换”。每一行会独立显示转换结果或错误。
4. 转换结束后在预览中检查 BPM、红绿时间线、音符和全谱导航条，再逐个或全部下载输出文件。

谱面视窗导航条位于预览上方，左侧显示当前小节的起始时间；长条表示当前预览范围，可拖动、点击或使用左右方向键移动。红线表示 BPM/拍号时间点，绿线表示 SV 时间点。它是局部检查视图，不是完整谱面播放器。

## 支持范围

当前仅支持 osu!standard 输入：圆圈转换为单点，滑条和转盘转换为长音符。Taiko 转换仍在制作中；Mania 与 Catch 输入暂不支持。具体规则见[在线页面](./)和[内核 README](../../../packages/osu-beatmap-converter/README.zh-Hans.md)。
