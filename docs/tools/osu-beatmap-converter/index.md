# osu! 铺面转换器（std → mania）

在浏览器本地批量读取、转换谱面文件。

## 参数说明

| 参数                 | 作用                                                                 |
| -------------------- | -------------------------------------------------------------------- |
| 目标键数             | 选择输出谱面的键数：1K、2K 或 4K。                                   |
| 变速处理             | 可保留全部变速、移除全部变速，或只移除绿线变速。                     |
| 纵连拆分策略         | 用预设快速设定下方两个纵连参数；需要微调时选择“自定义”。             |
| 普通音符轨道编号     | 指定普通音符写入哪条轨道。轨道从左到右依次为 1、2、3……。             |
| 交互段首音符轨道编号 | 指定交互段第一颗音符写入哪条轨道；之后的音符会在第 1、2 轨之间交替。 |
| 最小纵连间隔         | 两颗相邻音符的间隔小于这个值时，会被认作同一段纵连。                 |
| 最大纵连音符数       | 一段纵连超过这个数量时，会按交互段输出。                             |

页面默认输出 2K，并使用“默认预设”。选择 1K 时，轨道和纵连相关的四项参数不参与转换，因此会被锁定。选择文件或调整任一参数后，预览会立即刷新；下载按钮始终显示，转换前和转换中禁用，完成后启用。

## 转换规则

- Standard 圆圈转换为 Mania 音符，滑条和转盘转换为长音符。
- 当前仅接受 Standard 输入。Taiko 转换仍在制作中；Mania 与 Catch 输入暂不支持。

页面预览显示当前 BPM、节拍线、红线（BPM/拍号时间点）、绿线（SV 时间点）及音符/长音符。预览上方的谱面视窗导航条左侧显示当前小节的起始时间，长条表示当前预览范围，可拖动、点击或使用左右方向键移动。
